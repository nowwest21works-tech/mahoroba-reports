# mahoroba-reports

株式会社まほろばの **公開可能な不動産アプリ／ツール／沿線ガイド** を管理するPublic Repository。

## Current role

このRepositoryで管理するもの：

- `journey-map/` — 顧客条件・検討ジャーニーを扱う地図アプリ
- `map-circles/` — 地図描画・編集系ツール
- `area-guide/` — 公開用沿線・地域ガイド
- 上記を支えるtests / scripts / public assets

## Privacy rule

**顧客固有のレポート、氏名・イニシャルと物件情報を結び付ける成果物、個人情報を含むスクリーンショット等は、このPublic Repositoryへ保存しない。**

今後の顧客固有成果物は、アクセス制御された別の共有方法を使用する。
GitHubには匿名化・一般化した評価ロジック、公開可能なアプリ、再利用可能な技術資産のみを置く。

再利用可能な不動産比較・評価ロジックはPrivate `AICOS-Creative-OS` 側のIntelligenceとして管理する。

## Publishing gate

Public GitHub / GitHub Pages / ChatGPT Sites / その他公開URLへ出す前に、以下を確認する。

1. 顧客固有情報がない
2. 住所・氏名・連絡先・案件条件の組み合わせから個人を特定できない
3. 公開用データと内部判断メモが分離されている
4. 公開が本当に必要な成果物である

迷った場合は公開しない。
