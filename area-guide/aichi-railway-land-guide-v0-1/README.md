# 名古屋・愛知 土地探し沿線ガイド v0.1

## 目的

まほろば不動産の土地探し相談で使う、沿線・駅別の公開エリアガイドPreview。

## データソース

Notion「愛知県路線DB」「愛知県駅DB」を正本とする。

今回のPreviewでは、Notion MCPで以下を抽出した。

- 路線DB: 「対象区間」が空でない、かつ対象6路線
- 駅DB: 「公開ステータス = 進行中」、かつ「愛知県路線DB」リレーションが対象6路線に紐づく駅

駅名だけでは抽出していない。同名駅混入を避けるため、駅DBの「愛知県路線DB」リレーションで判定している。

## 現在の状態

Preview v0.1。

HTML掲載可はまだ正式公開判定には使っていない。将来の本公開モードでは「HTML掲載可 = YES」のみ出力できるよう、JSON側に `status` を保持している。

公開前にソースURL整備が必要。現在、主要ソースURLが空欄または鉄道会社公式URLのみのレコードがある。
