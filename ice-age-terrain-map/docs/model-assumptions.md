# モデル仮定と未解決事項

## DATA

- 入力標高はGEBCO_2026の現在の陸上・海底地形である。
- 標高の単位はメートル、水平座標はWGS84相当の緯度経度として扱う。
- Phase 1の現在海岸線近似は、同一入力の0 m等値面と外洋接続から抽出する。
- Phase 2の比較表示用現在海岸線はNatural Earth 10mを使用する。

## MODEL

- 代表年代: 約20,000年前
- 代表海水準: −120 m
- Web切替範囲: −140 m〜−80 m、5 m刻み、計13段階
- 陸地候補: `標高 > 指定海面`
- 水域候補: `標高 <= 指定海面`
- 推定海域: 水域候補のうち、ラスタ外周の水域候補へ4近傍で接続するセル
- 推定陸域: 推定海域ではないセル
- 新たに露出する陸棚: `推定陸域 AND 現在推定海域`

外周からのFlood Fillにより、内陸の窪地を海と誤認する問題を抑えます。ただし、外洋との接続幅が1セル未満の場合や入力標高の誤差がある場合、連結判定は変わります。

## STORY

地図から考えられる問いは、事実やモデル結果と別レイヤーで扱います。

- 現在の湾は、低海面期にはどのような河谷・平野として見えたか
- 現在の都市と台地・低地の位置関係はどう見えるか
- 海峡の接続・分断は、海水準だけでどこまで説明できるか

解説ポイントはDATA / MODEL / STORYを分離し、概略地形と細部形状の確度を別に示します。海峡部は「陸続き」「水路」の結論を断定せず、不確実性ポイントとして表示します。

## 計算範囲と表示範囲

- Flood Fill計算範囲: `120°E–150°E, 20°N–50°N`
- Web配信レビュー範囲: `122°E–147°E, 24°N–47°N`
- 座標系: WGS84経緯度
- Web配信用簡略化: 全13段階で0.005°を固定

面積値はこのレビュー範囲内のモデル陸域であり、日本の国土面積ではありません。外洋シードを安定させるため計算範囲は表示範囲より広く、表示範囲端にはクリップ境界が存在します。

## 再現していない要因

- 氷床荷重の変化とグレイシャル・アイソスタシー
- 地殻変動、活断層、隆起・沈降
- 約2万年間の堆積・侵食
- 河川流路、デルタ、砂州、湖沼の変化
- 地域ごとの相対海水準差
- 当時の地表被覆・植生
- GEBCO格子未満の水路・地形

## 未解決事項

1. 海面 −120 mを全国一律に適用する妥当性の地域別評価
2. 対馬・津軽・宗谷各海峡の接続判定を行う際の追加高解像度データ
3. Natural Earth海岸線とGEBCOの局所的な位置ずれの評価
4. 古河川候補の計算方法と「MODEL」表示の妥当性
5. 各解説ポイントの学術監修・出典
6. 0.005°簡略化が海峡・小島の細部へ与える影響
7. 相対海水準曲線と年代スライダーを結びつける研究選定
