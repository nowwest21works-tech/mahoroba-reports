# Phase 1.5 視覚・数値QAレビュー

## 判定

**Phase 2へ条件付きで進める。** 海面4段階で視覚差が明瞭で、13段階の配信容量も
Pilotとして現実的だった。一方、全国版をそのままWebレイヤーにする前に、
日本列島レビュー範囲に含まれる国外陸域の扱いを決め、瀬戸内海と3海峡の細い接続を
人間が確認する必要がある。

## 1. 生成した成果物

- 日本列島: 4海面の PNG / GeoJSON、2×2比較画像。
- 東海地方: 4海面の PNG / GeoJSON、2×2比較画像。
- −120 m 拡大: 東京湾、伊勢湾・濃尾平野・三河湾、瀬戸内海、対馬海峡、
  津軽海峡、宗谷海峡。
- 数値: CSV / JSON、簡略化前後、形状QA、13段階容量試算。
- 再現性: SHA-256付き `qa-manifest.json`。

全GeoJSONは `DATA / current_coastline`、`MODEL / lgm_land`、
`MODEL / exposed_shelf` の3 Featureを持つ。現在海岸線はGEBCO 0 m近似で、
独立した公的海岸線への置換は行っていない。

再生成はプロジェクト直下で次を実行する。

```powershell
.\.venv\Scripts\python.exe scripts\qa\build_phase_1_5_qa.py
```

既存の `outputs/qa/` が空でない場合は停止する。今回生成したQA成果物を明示的に
再生成するときだけ `--replace-generated-qa` を付ける。このオプションはPhase 1の
`outputs/lgm-*`、原本、メタデータを対象にしない。

## 3. 視覚変化が大きい地域

- **東京湾**: −120 mでは湾の大部分が推定陸域となり、現在との差が直感的。
- **伊勢湾・濃尾平野・三河湾**: 湾奥から外海側まで露出陸棚が連続し、東海版の
  主題として最も読み取りやすい。
- **瀬戸内海**: 広い範囲が陸化しつつ島・水路が複雑に残り、変化量が大きい。
- **宗谷海峡**: −120 mで広い連続陸域が現れ、4段階比較の差が大きい。

これらは地形モデルの見え方であり、当時の地表、河道、堆積、侵食、地殻変動を
復元した事実ではない。

## 4. 不自然または不安定な可能性がある地域

−120 mの1セル幅接続候補は、東京湾2、伊勢・三河湾0、瀬戸内海6、対馬海峡30、
津軽海峡18、宗谷海峡31だった。これは自動的な誤り判定ではなく、解像度依存の
接続を探す目視支援指標である。

- 瀬戸内海は小ポリゴン・細水路が多く、Web簡略化で形が変わりやすい。
- 対馬・津軽・宗谷海峡は島列と海峡縁で1セル接続候補が多い。
- 日本版には国外陸域が意図的に含まれ、接続QAには有用だが「日本全国版」配信には
  そのまま使えない。
- Phase 1 の既存 `outputs/manifest.json` は `age_label` の文字化けによりJSONとして
  解析できない。Phase 1.5成果物は別の有効な `outputs/qa/qa-manifest.json` に記録し、
  既存manifestは上書きしていない。
- 日付変更線は表示範囲外で、経度緯度順・EPSG:4326を確認した。
- 自己交差等は妥当化処理後に0件。処理前形状と簡略化前後の統計は保持した。

## 5. 現在海岸線の改善方針

全国縮尺は Natural Earth 1:10m Coastline + Minor Islands を第一候補とする。
代表6地域の詳細QAには国土地理院 基盤地図情報を基準候補として使う。Phase 1.5
の既存成果物はGEBCO 0 m近似のまま保持する。詳細は
`docs/current-coastline-options.md` に記録した。

## 6. Web MVPに適した形式

- 全国13段階: PMTiles。
- 東海詳細: 簡略化 GeoJSON + gzip でも実用的。
- 陰影起伏: ラスタタイルを別レイヤー。
- 未簡略化 GeoJSON: 配信せず、再生成・比較用の中間成果として保持。

13段階推計は日本簡略化GeoJSON 20.5 MB / gzip 2.60 MB / PMTiles概算
1.82〜2.86 MB、東海は 1.64 MB / 0.20 MB / 0.14〜0.22 MB。PMTilesは未変換の
計画値である。

## 7. Phase 2前に必要な修正

1. 日本版を「周辺を含む接続計算範囲」と「配信用の日本対象形状」に分ける。
2. 代表6地域に独立した現在海岸線を重ね、GEBCO 0 mとの位置差を確認する。
3. 瀬戸内海と3海峡で、簡略化前後・PMTiles化前後の接続状態を比較する。
4. 微小ポリゴン除去は一律実行せず、表示ズーム別の閾値を人間レビュー後に決める。
5. 13段階を実生成し、PMTiles実測容量とモバイル描画時間を確認する。
6. Phase 1 の既存manifestを、元成果物のハッシュを変えずに修復する手順を別途決める。

## 8. 精度・モデル上の注意

この地図は、現在の陸上・海底地形と推定海水準から生成した概算モデルである。
当時の堆積、侵食、地殻変動、河川流路、地表面を完全に復元していない。
「約2万年前」「海面−120 m」は代表的なモデル値で、地域・研究により差がある。
GEBCOは15秒格子であり、狭い海峡の開閉や小島を断定する解像度ではない。

## 9. 人間が判断すべき項目

- 宗谷海峡の−120 m陸橋表現を、ストーリーではなくMODELとしてどこまで強調するか。
- 津軽・対馬海峡の残存水路と1セル接続候補が許容できるか。
- 瀬戸内海の微小島・細水路を残す最小表示ズームと除去閾値。
- 「日本列島周辺」表示に国外陸域を残すか、日本対象の別レイヤーを作るか。
- Natural Earthで全国表示を行い、GSIをどの詳細ズームから採用するか。
- Phase 2の13段階生成前に追加の高解像度海底データ検証を行う地域。

優先して確認する画像は、宗谷海峡、対馬海峡、津軽海峡、瀬戸内海の4枚と、
日本列島・東海地方の比較コンタクトシートである。
