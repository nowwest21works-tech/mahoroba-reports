# 調査メモ

調査日: 2026-07-31

## 調査結果

### 1. 陸上・海底標高の取得

GEBCO_2026は陸上と海底を含む15 arc-second全球地形モデルで、公式サイトから全球ファイル、タイル、ユーザー指定範囲を取得できます。Pilot 01は公式範囲指定アプリのGeoTIFFを採用します。

### 2. 日本列島周辺の切り出し

公式サービスへWGS84 bboxを渡し、`120–150°E, 20–50°N` をサーバー側で切り出します。処理時はRasterio/GDAL windowで日本・東海表示範囲を再切り出します。

### 3. −120 m陸地の抽出

格子ごとに `elevation > -120` を陸地候補、`elevation <= -120` を水域候補とします。ただし最終陸域は外洋連結判定後に確定します。

### 4. 外洋接続水域の判定

水域候補の外周セルをシードに、4近傍のFlood Fill（連結成分探索）を行います。外周へ接続しない低地は海域にしません。表示bboxではなく余白を含む広い処理bboxで行います。

### 5. 利用条件とクレジット

GEBCO Gridは公式条件上パブリックドメインで無償利用可能です。出典表示、公式承認を示唆しないこと、誤表示をしないこと、航海・安全用途に使わないことが必要です。成果物と画面内に正式クレジットと免責を掲載します。

### 6. Vercel配信容量

Vercel公式Limitsの2026-07-31確認値:

- CLIデプロイ時のソースファイルアップロード合計: Hobby 100 MB、Pro 1 GB
- CLIデプロイのソースファイル数: 15,000
- ビルド上限: 45分
- Fast Data Transferの月間枠: Hobby 100 GB、Pro 1 TB

今回取得したGEBCO日本周辺GeoTIFFは103,731,024 bytesで、原本だけでHobbyのCLIソースアップロード上限を超えます。原本はGit/Vercel配信対象外とし、全国13レイヤーも直接同梱を初期案にしません。Phase 2ではビルド後容量、1レイヤー転送量、モバイル初期表示量を実測し、必要ならPMTilesを外部オブジェクトストレージへ置きます。

制限値はプラン・機能・更新時期で変わるため、公開着手時に再確認します。

### 7. GeoJSON / PMTiles / ラスタ

- Phase 1: GeoJSON。モデル結果と属性をレビューしやすい
- Phase 2: 陸域・海域はPMTiles第一候補。必要範囲のみ配信しやすい
- 背景: 陰影起伏はラスタタイルまたはCOG候補

公式参照:

- https://vercel.com/docs/limits
- https://maplibre.org/maplibre-gl-js/docs/examples/pmtiles/

## 判断

- データ版: GEBCO_2026
- 原本形式: GeoTIFF
- 処理範囲: 日本表示範囲より広い30°×30°
- 海域判定: 4近傍Flood Fill
- 現在海岸線: Pilot 01はGEBCO 0 m由来の表示用近似
- Phase 1配布形式: 簡略化GeoJSONとPNG
- Web MVP配布形式: PMTilesを優先評価

## 制約

- GEBCOは当時の地形ではない
- 全国一律−120 mは代表値
- 15 arc-second以下の水路・海峡は不安定
- bbox外周を外洋シードとするため、処理範囲の取り方が結果へ影響する
- 現況海岸線は独立した測量データではない
- Vercelの対象プランが未指定
