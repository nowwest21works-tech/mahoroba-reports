# UI判断

## 地図を主役にする

画面全体をMapLibre地図とし、タイトル、レイヤー操作、海面スライダー、解説を重ねました。初期値は約20,000年前の代表値−120 mです。−120 m以外へ動かすと「時代プリセットから変更」と表示し、年代と海面値を同一視しません。

## 色だけに依存しない

- 現在陸域: 淡い砂色
- 新たに露出する推定陸域: 橙色＋境界
- 現在海岸線: 濃色実線
- 推定海岸線: 明色破線
- 不確実性ポイント: 紫の`?`

凡例にはDATA / MODELを明記し、解説はDATA / MODEL / STORYの3ブロックへ分離しました。

## レスポンシブ

641px未満ではレイヤーパネルを閉じた状態で開始します。海面スライダーは画面下部へ固定し、地図操作と主要変化の比較を優先します。解説はスクロール可能なシートとして表示します。

## URL共有

`sea`、`lat`、`lng`、`zoom`、`layers`、`point`をquery parameterへ保存します。同じURLを再読込すると海面、表示位置、レイヤー、解説が復元されます。未定義値は安全な初期値へ正規化します。

## 情報量

都市は8地点だけを薄いラベルで表示し、河川は初期OFFです。現在海岸線はDATAとして常時比較可能にし、地形変化と操作の理解を妨げる一般地図タイルはMVPへ追加していません。
