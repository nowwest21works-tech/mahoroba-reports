# まほろばあちゃん｜土地探しの道案内

3つの質問（気になること・検討段階・エリア）から、次に確認する情報源を根拠付きで1〜2件案内する静的Pilotです。回答や任意メモはブラウザ内だけで扱い、送信・保存しません。

既存の不動産道具箱は読み取り専用の情報源として参照し、このフォルダからは変更しません。Google Maps / Street Viewは初期推薦にせず、通勤・現地環境を確認した後の補助導線に限定しています。

## Recommendation design

「エリア・立地」「暮らし・学校」の広すぎる入口を、3問のまま次の用途へ分けました。

- 通勤・通学・移動
- 価格・相場
- 学区・子育て
- 現地環境・暮らし

推薦は `dist/assets/app.js` の `recommendationPlan` で「関心 × 検討段階」を定義し、各道具の `areas` でエリア適合を判定します。カードには、推薦理由・まず見る場所・分かること・分からない境界・出典区分・スマホ利用条件を表示します。

代表例：

| 関心 | 検討段階 | エリア | 推薦 |
| --- | --- | --- | --- |
| 通勤・通学・移動 | エリア比較 | 名古屋市 | どこまで行けるマップ / シームレスバスマップ |
| 通勤・通学・移動 | エリア比較 | 愛知県外 | 希望エリア可視化マップ |
| 価格・相場 | エリア比較 | 愛知県内 | 土地代データ / 不動産情報ライブラリ |
| 建てられるか | 候補地あり | 愛知県内 | マップあいち / 不動産情報ライブラリ都市計画 |
| 学区・子育て | 候補地あり | 名古屋市 | 学区情報の検索入口 / マップあいち |
| 水害・地形 | すべて | すべて | 重ねるハザードマップ / 地理院地図 |

水害・地形のPilotは、水害・土砂災害などの公表レイヤーと地形を最初に確認するものです。地震・液状化・個別地盤まで網羅せず、自治体資料や専門調査を別に確認します。

## External link verification

2026-09-17に候補URLを直接取得し、HTTP 200・ページタイトル・viewportの有無を確認しました。

| 道具 | 出典区分 | スマホ条件 | 境界 |
| --- | --- | --- | --- |
| マップあいち | 愛知県の公的情報 | viewportあり | 市町村独自情報や個別判断は別確認 |
| どこまで行けるマップ（仮） | 民間サービス | viewportあり | 最新ダイヤ・待ち時間等は交通事業者で確認 |
| シームレスバスマップ | 民間・交通情報 | viewportあり | 非公式。改正未反映の場合あり |
| 土地代データ | 民間・相場入口 | viewportなし | スマホは拡大操作が必要。公的原典も確認 |
| 家造.net | 民間・学区検索入口 | viewportあり | 自治体公式ではない。番地単位は自治体確認 |

スーパー地形・古地図散歩などiOSアプリ限定の候補は、端末制約があるため初期推薦へ採用していません。

## Local preview

`dist/` を静的HTTPサーバーで配信してください。`file://` ではなくHTTPで確認します。

## Checks

自動確認：

```powershell
node tests/recommendations.test.cjs
```

自動テストは全192組合せについて、1〜2件、重複なし、エリア適合、Google Maps非推薦、必須説明項目、HTTPSを確認します。

人の代表確認では、390px幅でキャラクターの表示・表情・カードの読みやすさ、愛知と愛知県外での推薦差、外部サイトへ移動する前の説明を確認します。自動テストと人の判断は同一視しません。

## Next-stage data flow

次段階では、Notionを道具情報の正本とし、公開可能な項目だけをビルド時に静的JSONへ変換する想定です。

```
Notion（正本・人が更新）
  → build時に公開項目のみJSON化
  → 不動産道具箱（自由探索）
  → まほろばあちゃん（3回答から1〜2件を案内）
```

ブラウザからNotion APIへ接続せず、新DB作成や一括取込は行いません。公開項目の定義と同期実行は別のHuman Gateです。
